## 1. Real-Title COM Path vs. Synthetic Test-Harness Routing Map

### 1.1 Live Retail Guest Path (`SCARLETTX_REAL_TITLE=1` / `mainCRTStartup`)
Real Xbox Series X|S (`XboxGen9` / `Scarlett`) executables enter exclusively through the modules below:
- **Loader, VFS & Containers:** `src/loader/pe_mapper.cpp` (`PeMapper::MapAndRun` + transitive package/VFS DLL hooking), `src/loader/guest_modules.cpp` (`AttachTls`, `PatchHostModuleForGuests`), `src/loader/stub_thunk.cpp` (`StubThunkTable` with `.pdata` + `PAGE_EXECUTE_READ`), `src/loader/package_vfs.cpp` (`PackageVfs::Global()` with `shared_mutex` + LRU sector cache + zero-staging XVD `G:\` streaming), `src/loader/xvd_container.cpp` + `include/scarlettx/loader/aes_xts_cng.h` (`BCRYPT_XTS_AES_ALGORITHM` + 16B `.cik` GUID keyring), `src/runtime/emulator.cpp`, and `src/runtime/virtual_drive.cpp`.
- **Graphics & Shaders (`d3d12_xs.dll` / `xg_xs.dll`):** `src/shims/d3d12_xs_shim.cpp` COM vtable proxies (`D3D12XboxCreateDevice` -> `XboxD3D12*Proxy`), `src/shims/d3d12_xs_exports.cpp`, `src/gpu/shader_ir.cpp` (DXBC/DXIL chunk strip + `dxil.dll` re-sign + RDNA2 lifter), and `src/gpu/xg_layout.cpp` + `src/shims/xg_xs_shim.cpp:246-299` (`XGComputeOptimalSwizzleMode`, `XGCreateTexture2D/3DComputer`).
- **Storage, Audio & Input (`xcrdapi.dll` / `xaudio2_9.dll` / `GameInput.dll`):** `src/shims/dstorage_guest.cpp` (`xcrdapi.dll!DStorageGetFactory`, routed from `src/shims/dstorage_xs_forward.cpp`, wired to IETF `BTYPE=0/1/2` 32-lane GDeflate worker pool), `src/shims/xaudio2_guest.cpp` + `src/shims/xaudio2_null_output.cpp` + `src/shims/xaudio2_shim.cpp:714-1233` (`XAudio2Create`, `X3DAudio*`, `CreateFX`), `src/shims/acphal_shim.cpp`, and `src/shims/gameinput_shim.cpp` (`GameInputCreate` COM vtables).

## 2. Locked Architectural Decisions (Do Not Re-Litigate)

1. **Synthetic C-ABI Quarantine:** Zero-caller `src/kernel/{xmemory,xstorage}.cpp` and `XTaskQueueHle` are deleted, and `d3d12_xs_synthetic.cpp` is split from `d3d12_xs_shim.cpp`. Never add real-title functionality into synthetic C-ABI islands, and exclude synthetic-only DLLs (`xs2_lifting.dll`, `vulkan_backend.dll`, `xvc_crypto.dll`) from portable release `.zip` packages.
2. **Single Production Graphics Backend:** Commit 100% to **Host D3D12 + DirectX Agility SDK** (SM 6.6/6.8, Enhanced Barriers, DXR 1.1, Mesh Shaders, Work Graphs) behind `d3d12_xs`; treat `vulkan_backend.dll` as archived/non-production.
3. **Fail-Closed RDNA2 `XS2` Shader Pipeline:** Never map unknown RDNA2 opcodes to silent `v_fma_f32`/`v_mov_b32`/`s_nop` fallbacks or hardcoded geometry. Fail closed, dump failing shaders via `FlightRecorder`, and build clean-room **RDNA2 ISA -> SSA IR -> DXIL** directly inside `src/gpu/shader_ir.cpp` (migrating `.sxc` disk caching out of `xs2_lifting_shim.cpp`).
4. **Clean-Room Retail Media (`XMA2` & `Bink2`):** Execute title-bundled `Bink2Scarlett.dll` natively via package-first Multi-DLL Guest Hooking; for `XMA2` (`0x0166`) and unbundled fallback codecs, support optional runtime `LoadLibraryW` of user-installed external LGPL FFmpeg (`avcodec-*.dll`) outside the repository, falling back to deterministic silent-PCM timing rather than static noise when absent.

## 4. Remaining Post-M3 Technical Debt & Traps

1. **Real `kernelx.dll` GameOS Exports & Lock-Free VA Map (`src/kernel/kernelx_shim.cpp`):** Commercial titles importing `AllocateTitlePhysicalPages`, `FreeTitlePhysicalPages`, `MapTitlePhysicalPages`, `TitleMemoryStatus`, `JobTitleMemoryStatus`, or `WaitOnAddress` hit `StubThunk`, and `KernelXMapVirtualToGpu` still uses a mutex-locked $O(N)$ map scan.
2. **RDNA2 `XS2` Silent Miscompilation & Trapped `.sxc` Cache (`src/gpu/shader_ir.cpp:791-1962`, `src/gpu/xs2_lifting_shim.cpp:2619-2750`):** Unknown VOP3/VOP2/VOP1/MIMG opcodes in `shader_ir.cpp` still fall back to `v_fma_f32`/`s_nop`/`v_mov_b32` instead of failing closed, and the versioned `.sxc` shader disk cache lives in unreachable `xs2_lifting.dll`.
3. **AMD `ADDR2` `_X` Pipe/Bank XOR Swizzles & `CreatePlacedResourceX` `4KB_S` Assumption (`src/gpu/xg_layout.cpp:219-280`, `src/shims/d3d12_xs_shim.cpp:1845`):** `64KB_S_X` / `64KB_D_X` / `64KB_R_X` textures lack pipe/bank XOR equations, and `BindExternalGuestTextureMemory` still assumes `4KB_S`.
4. **Retail `XMA2` (`0x0166`) & Fallback `Bink2` Noise (`include/scarlettx/audio/xma2_decoder.h:891-1089`, `src/shims/bink2_scarlett_shim.cpp:208-247`):** Must replace pseudo-decoded WMA-Pro static noise and compressed-byte modulo video noise with optional runtime `LoadLibraryW` of external user-installed LGPL `avcodec-*.dll` + deterministic silent/black PTS-accurate fallback when absent.
5. **DirectStorage GPU Destinations (`src/shims/dstorage_guest.cpp`) & Async HTTP (`src/shims/libhttpclient_shim.cpp`, `src/shims/xcurl_shim.cpp`):** Port `ID3D12Resource` buffer/`CopyTextureRegion` destinations into `dstorage_guest.cpp` (`xcrdapi.dll`), chunk `XCurl` `write_cb` to `16 KiB` (`CURL_MAX_WRITE_SIZE`), and make live `WinHTTP` asynchronous so `XTaskQueue` threads never block.
